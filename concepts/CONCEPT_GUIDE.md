# UI Concept Boards — Review Guide

These concept boards were generated from the written Glass Layered UI specification in this package. They are exploratory mood/layout references, not product specifications or exact implementation targets.

## Concept 01 — Dark Glass Layered

`01-dark-glass-layered-concept.png`

Use this to assess the dark graphite surfaces, red primary actions, reminder cards, navigation, map/radius preview, and onboarding treatment. This is the closest visual direction for the primary app screens.

## Concept 02 — Developer Tools Extension

`02-developer-tools-concept.png`

Use this to assess how a development-only configuration screen might fit alongside the regular app. The Developer Tools screen should use the same visual language but have a clear `DEV BUILD` label and must not appear in production.

## Review caveats

- Generated imagery can contain misspelled text, inconsistent labels, or arbitrary values. Do not copy its text, radius values, timing values, package names, or feature claims.
- The canonical production values are 200m, below 2 mph, and 120 seconds stationary inside the geofence.
- The user-facing Create Reminder screen must not offer radius selection.
- The images are for confirming general visual direction: deep graphite, smoked translucent layers, subtle borders, restrained red accents, rounded cards, readable typography, and a premium instrument-panel feel.
