# Glass Layered UI Kit

This kit contains the generated multi-screen concept board, a reusable background image, SVG icons, and a technical design specification.

## Start here
1. Open `screens/glass_layered_multi_screen_concept.png`.
2. Read `spec/GLASS_LAYERED_TECHNICAL_DESIGN_SPEC.md`.
3. Import design values from `spec/design_tokens.json`.
4. Use the background at `assets/backgrounds/glass_frosted_geometric_background.png`.
5. Use SVG icons in `assets/icons/`.

All dimensions are Flutter logical pixels (dp) unless explicitly noted. The concept board is a visual reference; it is not editable Figma source or production UI code.
