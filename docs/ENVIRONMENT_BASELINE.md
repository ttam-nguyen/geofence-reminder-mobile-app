## Known Issues / Notes

1. **JDK version mismatch:** System JDK is 26 but RN expects >=17 <=20. Resolved by setting `JAVA_HOME` to OpenJDK 17 for all Android builds. Add to shell profile or build scripts:
   ```bash
   export JAVA_HOME=$(/usr/libexec/java_home -v 17)
   ```

2. **Gradle deprecation warning:** "Deprecated Gradle features were used in this build, making it incompatible with Gradle 10." This is from the template; acceptable for now.

3. **CocoaPods warnings:** Script phases added by `React-Core-prebuilt`, `ReactNativeDependencies`, and `hermes-engine`. Template-generated; acceptable.

4. **Android emulator startup:** Requires `-gpu swiftshader_indirect` flag on this system for GPU acceleration. The emulator boots fine without a display (`-no-window`).

5. **Port 8081 conflicts:** Metro bundler may already be running from a previous session. Kill with `lsof -ti:8081 | xargs kill -9` before running.
