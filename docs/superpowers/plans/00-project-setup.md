# Plan 0: Project Setup & Verification Baseline

## Feature Name
Project Scaffolding — React Native Geofence Reminder App

## Goal
Establish a working React Native project skeleton with TypeScript, testing, linting, and type-checking. Verify build succeeds on both iOS and Android before any feature code.

## Architecture
- React Native 0.74+ (supports iOS 13+, Android API 29)
- TypeScript 5.x strict mode
- Metro bundler for JS bundling
- CocoaPods for iOS native deps
- Gradle (AGP 8.x) for Android

## Tech Stack
| Layer | Choice | Rationale |
|---|---|---|
| Framework | React Native 0.74+ | Cross-platform, iOS 13+/Android 29+ support |
| Language | TypeScript 5.x strict | Type safety, spec §9 data models |
| State | Zustand v5 | Lightweight, no boilerplate, TypeScript-first |
| Navigation | React Navigation 6.x | Standard RN navigation, deep linking support |
| Storage | react-native-sqlite-storage v7 | Local SQLite, source of truth per spec §9 |
| Testing | Vitest + React Native Test Renderer | Fast unit tests, spec §10 |
| Linting | ESLint + TypeScript ESLint | Code quality baseline |
| Formatting | Prettier | Consistent style |

## Spec References
- §2 Platforms: iOS and Android
- §10 Quality: build/test/lint commands must exist
- §11 Plan 0 (Foundation)

## Global Constraints
- Must compile on both iOS and Android simulators
- Must pass `tsc --noEmit` with zero errors
- Must pass ESLint with zero errors
- Minimum versions: iOS 13.0, Android API 29 (Android 10)
- Node.js 18+ required

## Review Focus
- Project compiles without errors
- Both iOS and Android build targets produce artifacts
- Test runner executes successfully (even with no tests yet)
- Linter passes on scaffolded code

## Tasks (Checkbox — Test-First)

- [ ] **Step 0.1:** Install Node.js 18+ if not present
  - Command: `node --version` (expect v18.x or higher)
  - Expected: Node version ≥ 18.0.0

- [ ] **Step 0.2:** Create React Native project
  - Command: `npx react-native init GPSReminder --directory . --skip-git-init`
  - Expected: Project scaffolded in current directory, `package.json` created, `android/` and `ios/` directories present

- [ ] **Step 0.3:** Add TypeScript configuration
  - Create `tsconfig.json` with `strict: true`, `jsx: react-native`
  - Command: `npx tsc --noEmit`
  - Expected: Zero errors in scaffolded code

- [ ] **Step 0.4:** Configure ESLint
  - Create `.eslintrc.js` with `@typescript-eslint/parser`, `@react-native/eslint-config`
  - Command: `npx eslint src/`
  - Expected: Zero errors

- [ ] **Step 0.5:** Configure Prettier
  - Create `.prettierrc.js` with React Native presets
  - Command: `npx prettier --check src/`
  - Expected: Zero formatting issues (or auto-fix and verify)

- [ ] **Step 0.6:** Configure testing framework
  - Add `vitest` or `jest` + `@testing-library/react-native`
  - Create `src/__tests__/App.test.tsx` — basic render test
  - Command: `npx vitest run` or `npx jest`
  - Expected: Test passes (renders root component without crash)

- [ ] **Step 0.7:** Verify iOS build
  - Command: `cd ios && pod install && cd .. && npx react-native run-ios --simulator "iPhone 14" --no-packager`
  - Expected: iOS app installs and launches in simulator without crash

- [ ] **Step 0.8:** Verify Android build
  - Command: `npx react-native run-android --variant=debug`
  - Expected: Android app installs and launches on emulator without crash

- [ ] **Step 0.9:** Create commit
  - Command: `git add . && git commit -m "chore: project scaffold with TypeScript, ESLint, Prettier, test baseline"`
  - Expected: Clean commit at revision `v0-scaffold`

## Verification Commands

```bash
# TypeScript check
npx tsc --noEmit

# Lint check
npx eslint src/

# Format check
npx prettier --check "src/**/*.{ts,tsx}"

# Test execution
npx vitest run    # or npx jest

# iOS build (release)
cd ios && pod install && cd ..
xcrun xcodebuild -workspace ios/GPSReminder.xcworkspace -scheme GPSReminder -configuration Debug -sdk iphonesimulator -arch x86_64

# Android build (debug)
cd android && ./gradlew assembleDebug && cd ..
```
